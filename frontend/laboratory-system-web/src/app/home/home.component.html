Para enviar reportes por WhatsApp, es necesario tener instalada la aplicación de escritorio. El sistema utilizará el número de teléfono registrado del paciente para facilitar el envío.

PROTECCIÓN DE LA INFORMACIÓN

Copias de seguridad y recuperación.

Configura la estrategia de respaldo de la aplicación, define la frecuencia de ejecución y consulta el historial para verificar el estado de las copias de seguridad.

06

Configuración de backups

Configuración inicial

Define cómo y cuándo se realizarán las copias de seguridad de la aplicación. Podrás seleccionar el modo automático o manual y establecer los intervalos de ejecución que necesite el laboratorio.

  • Modo automático: ejecuta las copias según la programación configurada.
  • Modo manual: permite iniciar una copia de seguridad cuando el usuario autorizado lo necesite.
  • Respaldo integral: contempla los datos y componentes necesarios para recuperar la aplicación, de acuerdo con el alcance de la estrategia de respaldo implementada.
  • Intervalos: permite configurar la frecuencia de ejecución de las copias automáticas.
Configurar copias de seguridad
07

Reporte de backups

Seguimiento

Consulta el historial de las copias de seguridad y verifica el resultado de cada ejecución para conocer si el respaldo se completó correctamente o requiere atención.

  • Fecha y hora de ejecución.
  • Tipo de respaldo: automático o manual.
  • Estado: en progreso, completado o fallido.
  • Duración, ubicación y detalles del resultado, cuando estén disponibles.

SEGURIDAD Y PERMISOS

Controla quién puede acceder y administrar.

La autenticación identifica al usuario y sus permisos determinan las funciones y los datos que puede gestionar. El acceso debe respetar el rol asignado en toda la aplicación.

08

Autenticación y control de acceso

Acceso seguro

Cada usuario debe autenticarse para acceder a las funcionalidades autorizadas. El sistema utiliza los roles Role_admin y Role_user para aplicar los permisos correspondientes.

Las restricciones deben aplicarse tanto en la interfaz como en el servidor o API. Ocultar botones en pantalla no sustituye la validación de permisos en las operaciones de lectura y escritura.

Consultar configuración de seguridad
09

Administrador — Role_admin

Acceso completo

El administrador dispone de acceso a todas las funcionalidades autorizadas de la aplicación para gestionar su configuración y operación.

  • Crear, consultar, modificar y eliminar las entidades que administra la aplicación.
  • Gestionar categorías, contactos y catálogo de pruebas.
  • Gestionar pacientes, órdenes y resultados.
  • Configurar los backups y consultar sus reportes.
  • Administrar usuarios, roles y permisos, si estas funciones están habilitadas en el sistema.
10

Usuario estándar — Role_user

Acceso limitado

El usuario estándar puede gestionar los datos necesarios para el flujo de trabajo clínico y operativo, sin disponer de permisos administrativos sobre las demás entidades.

  • Pacientes: consultar, registrar, modificar y eliminar, conforme a los permisos asignados.
  • Órdenes: crear, consultar, modificar y eliminar órdenes, conforme a las reglas del flujo de trabajo.
  • Resultados: registrar, consultar, modificar y eliminar resultados, según las autorizaciones establecidas.
  • Categorías: acceso de consulta, sin permisos para crear, modificar ni eliminar.
  • Contactos: acceso de consulta, sin permisos para crear, modificar ni eliminar.
  • Catálogo de pruebas: acceso de consulta, sin permisos para crear, modificar ni eliminar.
  • Configuración y seguridad: sin permisos para administrar usuarios, roles, configuración global o políticas de backups.

Los permisos de consulta sobre categorías, contactos y catálogo deben habilitarse explícitamente. Si el usuario no necesita consultar alguna de estas entidades, su acceso también debe denegarse.
